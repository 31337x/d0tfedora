# Keyboard shortcuts

Exact bindings from the bundled Niri configuration. Mod means Super/Windows.


## Hardware Controls

| Shortcut | Action |
| --- | --- |
| XF86AudioRaiseVolume | Increase Speaker Volume |
| XF86AudioLowerVolume | Decrease Speaker Volume |
| XF86AudioMute | Mute/Unmute Speakers |
| XF86AudioMicMute | Mute/Unmute Microphone |
| XF86MonBrightnessUp | Increase Screen Brightness |
| XF86MonBrightnessDown | Decrease Screen Brightness |

## Applications
