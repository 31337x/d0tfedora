# Validation

Cleanup checks:

- Bash/POSIX shell syntax and standalone/embedded Python compilation.
- All JSON and TOML parse successfully.
- Niri configuration validates with the installed Niri.
- Noctalia configuration validates with zero warnings.
- Installer help, dry-run and invalid-option handling.
- Last Horizon fzf colors are generated by Noctalia and accepted by fzf.
- Greeter seed generation preserves unrelated settings and removes stale monitor assignments.
- Cheatsheet files and all keyboard shortcuts remain intact.
- Codex theme selection preserves existing settings and is unchanged on reruns.
- The bundled Codex template renders valid Noctalia syntax colors from Last Horizon.
- Lock screen widgets, monitor placements, fade and idle timers match the saved desktop configuration; avatar and wallpaper use installer-expanded home paths.
- Startup seeding creates compact boxes for unfamiliar landscape and portrait outputs, updates widget order, preserves existing settings and is unchanged on reruns.
