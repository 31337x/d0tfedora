# Sharing review

The bundle retains third-party wallpapers, the Paradise palette and the core MIT-declared keybind cheatsheet plugin. The owner previously confirmed permission to republish these assets. No project-wide license is imposed on third-party work.

Wallpaper metadata is retained; `assets/Wallpapers/007.jpg` contains camera/lens serial-number metadata. Downloaded images are not represented as photographs taken by this project's author. Original wallpaper names are recorded in `assets/wallpaper-map.json`.

Home paths in Noctalia settings use `__HOME__`, rendered during setup. Plugin fixtures use synthetic `/home/test` paths. Removed plugins, community application templates and download catalogs are excluded. Ignore rules cover common credential files, editor state and backups; they cannot prevent secrets being added to tracked files.
